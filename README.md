# Charity:Water Landing Page

A simple, single-page HTML landing page for Charity:Water, recreated from a design template.

## What's inside

- `index.html` — the full page (HTML + CSS, no build tools needed)
- `assets/logo.png` — the Charity:Water logo mark
- `assets/hero_photo.png` — the hero image

## How to use

1. Download or clone this repo.
2. Open `index.html` directly in your browser — that's it, no setup required.

## Deploying with GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under "Build and deployment," set the source branch to `main` (or whichever branch you used) and the folder to `/ (root)`.
4. Save — GitHub will give you a live URL in a minute or two.

## Customizing

- Edit the text and button link directly in `index.html`.
- Swap `assets/hero_photo.png` for your own image (keep the same filename, or update the `<img src="">` path).
- Colors are defined as CSS variables at the top of the `<style>` block in `index.html` if you want to adjust the palette.
